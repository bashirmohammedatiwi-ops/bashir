  ربط منتجات ilove بمجلدات Google Drive في Excel
═══════════════════════════════════════════════════════

مجلد الصور على Drive:
https://drive.google.com/drive/folders/1aL2XkJoBapgOtmOqXVYqvftAB2xxxTiI

المجلد حالياً خاص (يتطلب تسجيل دخول Google) — لذلك لا يمكن
سحب روابط المجلدات تلقائياً من هنا بدون خطوة واحدة منك.

───────────────────────────────────────────────────────
الطريقة الأسهل (دقيقتان) — من المتصفح
───────────────────────────────────────────────────────

1. افتح الرابط أعلاه وسجّل دخولك في Google Drive

2. اضغط F12 → تبويب Console (وحدة التحكم)

3. افتح الملف extract-drive-map.js من هذا المجلد،
   انسخ كل محتواه والصقه في Console ثم Enter

4. سيُحمَّل ملف drive-map.json تلقائياً
   → انقله إلى هذا المجلد: ilove-brand-export/

5. شغّل من PowerShell:
   cd backend
   npx tsx scripts/link-ilove-drive-excel.ts

6. افتح ilove-products.xlsx — ستجد أعمدة:
   • رابط مجلد درايف
   • رابط درايف صورة رئيسية
   مملوءة لكل منتج

───────────────────────────────────────────────────────
طريقة بديلة — مفتاح API (إذا شاركت المجلد علناً)
───────────────────────────────────────────────────────

1. في Drive: مشاركة المجلد → "أي شخص لديه الرابط" → عرض

2. Google Cloud Console → تفعيل Drive API → إنشاء API Key

3. شغّل:
   cd backend
   $env:GOOGLE_DRIVE_API_KEY="مفتاحك"
   npx tsx scripts/link-ilove-drive-excel.ts
