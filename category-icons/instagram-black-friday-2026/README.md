# بوستات إنستغرام — الجمعة السوداء 2026

7 براندات (ليراك، بيوديرما، فيتو، بيزلين، ريفوكس، ديرمولاب، ديبورا)، 57 صورة 1080×1350 (تُصدَّر 2160×2700).
الصور النهائية على سطح المكتب: `Instagram Black Friday 2026/<براند>/01.jpg…`، والمعاينات هنا `final_*.jpg`.

- `kit.js` أنواع الشرائح (app غلاف بالهاتف والمنتجات، hero، offer، spotlight، grid، cta) وعالم بصري لكل براند
  (`THEMES`)، وأيقونة التطبيق + «متوفر على App Store» + «في محل ديما الحياة وعلى التطبيق» في كل صورة.
- `brands/<brand>.json` محتوى كل بوست (المنتجات بالمعرّف من الكتالوج، النِّسب، النصوص).
- `tools/cutout2.js` قص المنتجات بنموذج BRIA RMBG-1.4 (يحلّ محل `cutout.js` القديم).
- `run.js <brand>` يولّد البوست، `sheet.js` ورقة مراجعة، `prep.js` تجهيز منتج جديد.
