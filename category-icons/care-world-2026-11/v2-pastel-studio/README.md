# طقوس العناية v2 — «استوديو باستيل» (5 تشرين الثاني 2026)

مستوحى من مرجع العميل: كل قسم كتلة ملوّنة = بنر عريض (3:1) + مربعان + صف لوحات صغيرة + منتجات.
- لون لكل قسم: الوجه وردي، الشعر لافندر، الجسم رملي، الشمس ذهبي، الكورية نعناعي، الطبية سماوي، الجمعة السوداء رمادي ليلكي.
- المنتجات صور الكتالوج (خلفية بيضاء) تُدمج بـ `mix-blend-mode:multiply` على قوس ومنصّة فاتحين — بلا أي قص.
- البنرات العريضة فيها نافذة مقوّسة بصورة حملة رسمية.

الترتيب: الشريط ← البنرات العلوية ← «تسوّقي حسب الحاجة» (فهرس ملوّن 3×2) ← شعارات البراندات ←
عروض الجمعة السوداء (تختفي بعد 28/11) ← عالم إيفولوديرم ← الوجه ← الشعر ← الجسم ← الشمس ← الكورية ← الطبية ← حسب احتياج بشرتك ← عروض طقوس العناية.

- `scripts/fetch.js` يجلب صور المنتجات المرشّحة (`queries.json` → `cands.json`, غير محفوظ هنا لحجمه).
- `scripts/kit2.js` + `designs2.json` القوالب والمواصفات؛ `plan2.js` الروابط والمجموعات؛ `mock2.js` المعاينة.
- `scripts/publish-care4.js` + `plan.json` النشر داخل حاوية الـ API (`/tmp/care4`).
