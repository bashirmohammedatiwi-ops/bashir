# manager-app — تطبيق المدير (Flutter)

تطبيق هاتف للمدير والموظفين، مبني على مسارات `/api/v1/control` في الباك‌إند.

## الميزات

- **البحث بالباركود**: كاميرا الهاتف (مسح واحد أو متتالٍ)، كتابة الرقم، أو قارئ باركود بلوتوث/USB بوضع لوحة المفاتيح — يعمل من أي شاشة.
- **بحث شامل**: الاسم بالعربي/الإنجليزي، البراند، SKU، الباركود، واسم أو باركود أي تدرج — يشمل المنتجات الموقوفة.
- **تشغيل/إيقاف** المنتج أو أي تدرج بمفتاح واحد (التدرج الموقوف يختفي من التطبيق والموقع ولا يُطلب).
- **الصور**: إضافة (كاميرا/معرض، عدة صور)، ترتيب بالسحب، تعيين الغلاف، استبدال، حذف، **قص وتدوير** (يُقص على السيرفر من الأصل بدقة كاملة)، قص الحواف تلقائياً، إطار مربع أبيض لكل الصور دفعة واحدة — مع **تراجع**.
- **التدرجات**: صورة لكل تدرج (كاميرا، معرض، أو من صور المنتج) مع القص، الاسم، اللون، الباركود، وإيقاف جماعي (الكل / النافدة).
- **الباركودات الناقصة**: منتج غير موجود ← احفظ باركوده وصوره في **مجموعة** (رف، طلبية...) مع اسم الكاشير تلقائياً. يتحول للأخضر تلقائياً حين يُضاف المنتج لاحقاً. يظهر في لوحة التحكم ← «الباركودات المحفوظة».
- **الطلبات**: تبويبات حسب الحالة مع العدد، تفاصيل الطلب، اتصال وواتساب للزبونة، نقل الحالة بزر واحد (تأكيد ← تحضير ← شحن ← تسليم)، إلغاء آمن (يعيد المخزون ويسترجع دفعة البطاقة)، و**تجهيز بالمسح**: امسح كل قطعة لتتأكد أن الطلب مكتمل. تنبيه داخل التطبيق عند وصول طلب جديد مع شارة العدد.
- **المبيعات** (للمدير فقط): اليوم مقابل أمس، 7 و30 يوماً، متوسط الطلب، رسم 14 يوماً، والأكثر مبيعاً فعلياً.
- **إضافة منتج من الهاتف**: من باركود غير موجود أو مسودة أو صنف كاشير — تعبئة ذكية (اسم، براند، قسم، صور)، صور من الكاميرا أو من الويب والمتاجر، براند جديد بالاسم، والسعر والمخزون من الكاشير تلقائياً.
- **تدرج جديد لمنتج موجود** بمسح باركوده، مع صورة ولون؛ وحذف التدرجات.
- **نواقص الكاشير**: أصناف لها مخزون في الكاشير وغير معروضة في التطبيق، الأكثر مخزوناً أولاً — أضفها أو احفظها أو اربطها كتدرج.
- تعديل البراند والقسم، وتحديد عدة منتجات لتشغيلها أو إيقافها معاً.
- لوحة سريعة: أرقام (موقوف، بلا صور، نافد، تدرجات موقوفة)، آخر عمليات المسح، وسجل التعديلات (من عدّل ماذا).

## التشغيل

```bash
cd manager-app
flutter pub get
flutter run
```

السيرفر الافتراضي `https://deemaalhayat.com/api/v1`. للتجربة المحلية:

```bash
flutter run --dart-define=API_BASE_URL=http://localhost:3000/api/v1
```

## البناء

```bash
flutter build apk --release        # Android
flutter build ipa --release        # iOS
```

## قارئ باركود خارجي

اربط القارئ بالهاتف كلوحة مفاتيح (Bluetooth HID أو USB-OTG) واضبطه ليرسل Enter بعد الباركود. التطبيق يلتقط القراءة من أي شاشة ما دام لا يوجد حقل كتابة مفعّل؛ في حقل البحث تُكتب القراءة فيه مباشرة.
