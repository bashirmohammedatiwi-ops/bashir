# تطبيق تجهيز الطلبات — ديما الحياة (fulfillment-app)

تطبيق Flutter مخصّص وبسيط لموظفي تجهيز الطلبات. واضح وسريع ومركّز على مهمة واحدة: استلام الطلبات وتجهيزها بدقّة وتسليمها للتوصيل.

## الخصائص
- **طابور طلبات حيّ**: تبويبات حسب الحالة (المفتوحة، جديدة، مؤكدة، قيد التحضير، جاهزة، مكتملة) مع العدد، وبحث برقم الطلب أو اسم/هاتف الزبونة.
- **تنبيه الطلبات الجديدة**: فحص حيّ كل 45 ثانية مع صوت/اهتزاز عند وصول طلب، وإشعار في الخلفية والتطبيق مغلق (أندرويد).
- **التجهيز بمسح الباركود**: فتح الطلب → «تجهيز بالمسح» → مسح باركود كل قطعة (كاميرا أو قارئ خارجي بلوتوث/USB) مع عدّاد لكل سطر وشريط تقدّم وتحقّق من المطابقة وإكمال تلقائي، ثم زر «اعتماد التجهيز».
- **نقل الحالة** بزر واحد كبير: تأكيد ← بدء التحضير ← جاهز للتوصيل ← تم التسليم.
- **أدائي**: عدد الطلبات المجهّزة اليوم/الأسبوع ومتوسط زمن التجهيز (محسوب محلياً على الجهاز).
- مشاركة/نسخ ملخّص الطلب والاتصال/واتساب بالزبونة.

## التقنية
- Flutter + Riverpod + Dio، عربي RTL بالكامل، خط Cairo.
- يتصل بـ backend المنصة عبر نقاط `/control/orders` المتاحة لدور **STAFF** — بلا أي تعديل في الـbackend.
- الدخول مسموح فقط لحسابات STAFF / ADMIN / SUPER_ADMIN.

## التشغيل
```bash
flutter pub get
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:3077/api/v1
```
- المحاكي (أندرويد): استخدم `10.0.2.2` للوصول إلى السيرفر المحلي.
- الإنتاج الافتراضي: `https://deemaalhayat.com/api/v1` (انظر `lib/core/config.dart`).
- لتعبئة بيانات الدخول في التطوير: أضف `--dart-define=DEV_EMAIL=...` و `--dart-define=DEV_PASSWORD=...`.

## البنية
```
lib/
  core/      config, api, theme, format, prefs, scanner_bus, background
  data/      models, repo, session
  features/  auth, shell, orders (الطابور + التفاصيل/التجهيز), scan, stats, settings
  widgets/   common
```
التطبيق مبني بإعادة استخدام نواة `manager-app` المجرَّبة مع تبسيطها وتركيزها على التجهيز فقط.
