## 3) نماذج «محتوى التطبيق» (App content)

### الوصول إلى التطبيق (App access)
اختر: **بعض الميزات محدودة**، وأضف حساباً تجريبياً للمراجِع:
- أنشئ حساب زبونة تجريبياً من التطبيق (رقم هاتف + كلمة سر) وضع بياناته هنا.
- التعليمات: `التصفح متاح بدون تسجيل. لإتمام طلب: سجّل الدخول بالحساب أعلاه ← أضف منتجاً للسلة ← إتمام الطلب. الدفع عند الاستلام؛ الدفع بالبطاقة غير مفعّل بعد.`
- نبّه الموظفين أن طلبات هذا الحساب تجريبية ولا تُشحن.

### الإعلانات (Ads)
**لا، التطبيق لا يحتوي على إعلانات.**

### معرّف الإعلانات (Advertising ID)
**لا** — التطبيق لا يستخدم معرّف الإعلانات (لا توجد صلاحية AD_ID في التطبيق).

### تقييم المحتوى (Content rating)
- الفئة: **Consumer Store or Commercial Streaming Service** (متجر).
- عنف/جنس/لغة/مخدرات/قمار: **لا** لكل الأسئلة.
- هل يتفاعل المستخدمون أو يتشاركون محتوى؟ **نعم** — تقييمات المنتجات تظهر للآخرين (تُراجَع ويمكن إخفاؤها من لوحة التحكم).
- مشاركة الموقع: **لا**. شراء سلع مادية: **نعم**.
- النتيجة المتوقعة: مناسب للجميع / 3+.

### الجمهور المستهدف (Target audience)
اختر **18 سنة فأكثر** (يجنّب التطبيق سياسة العائلات والأطفال).

### الميزات المالية (Financial features)
**التطبيق لا يقدّم خدمات مالية** (متجر سلع؛ الدفع عند الاستلام).

### الصحة (Health)
**لا يوجد**.

### تطبيق حكومي / أخبار / كوفيد
**لا**.

### حذف البيانات
- رابط حذف الحساب: **https://deemaalhayat.com/delete-account**
- يمكن حذف الحساب من داخل التطبيق أيضاً: حسابي ← حذف الحساب.

### أمان البيانات (Data safety)

الأسئلة العامة:
- هل يجمع التطبيق أو يشارك بيانات؟ **نعم**
- هل البيانات مشفّرة أثناء النقل؟ **نعم** (HTTPS)
- هل يمكن طلب حذف البيانات؟ **نعم** (الرابط أعلاه)

البيانات التي تُجمع — **لا شيء منها يُشارك** مع أطراف ثالثة (شركة التوصيل تعمل نيابة عن المتجر، وهذا لا يُعدّ «مشاركة» في تعريف Google). ولا شيء منها يُستخدم للإعلانات:

| النوع في Play | البيانات | إلزامي؟ | الغرض |
|---|---|---|---|
| المعلومات الشخصية ← الاسم | اسم الزبونة | إلزامي | وظائف التطبيق، إدارة الحساب |
| المعلومات الشخصية ← رقم الهاتف | للدخول والتوصيل | إلزامي | وظائف التطبيق، إدارة الحساب |
| المعلومات الشخصية ← العنوان | عنوان التوصيل | إلزامي للطلب | وظائف التطبيق |
| المعلومات المالية ← سجل المشتريات | الطلبات | إلزامي للطلب | وظائف التطبيق |
| نشاط التطبيق ← سجل البحث داخل التطبيق | كلمات البحث (بدون ربط بالحساب) | إلزامي | التحليلات (تحسين البحث) |
| نشاط التطبيق ← محتوى من إنشاء المستخدم | تقييمات المنتجات | اختياري | وظائف التطبيق |
| نشاط التطبيق ← تفاعلات أخرى | المفضلة وتنبيهات عودة المنتج | اختياري | وظائف التطبيق، التخصيص |
| معرّفات الجهاز | رمز الإشعارات (Firebase) | اختياري | وظائف التطبيق (الإشعارات) |

لا يجمع التطبيق: الموقع الجغرافي، الصور أو الفيديو، جهات الاتصال، الرسائل، الصحة، بيانات البطاقات.
الكاميرا تُستخدم لمسح الباركود فقط، والصورة تُعالَج على الجهاز ولا تُرسل.

## 4) الرفع

1. **أنشئ مفتاح الرفع** (مرة واحدة):
   ```
   bash google-play/create-upload-key.sh
   ```
   اكتب كلمة سر تختارها. احفظ مجلد `~/deema-keys/customer-app` وكلمة السر في مكان آمن.
2. **ابنِ ملف التطبيق** (أو اطلب من Claude):
   ```
   cd mobile-app && flutter build appbundle --release
   ```
   الملف: `mobile-app/build/app/outputs/bundle/release/app-release.aab`
3. في Play Console: **Testing ← Internal testing ← Create release**، ارفع الملف، ووافق على **Play App Signing**.
4. **حساب شخصي جديد:** يجب اختبار مغلق (Closed testing) مع **12 مختبِراً على الأقل لمدة 14 يوماً** قبل طلب النشر للعامة (Production).
   **حساب منظمة/شركة:** يمكن النشر للعامة مباشرة.
5. بعد أول رفع: **Setup ← App integrity ← App signing** وانسخ بصمة **SHA-256** لمفتاح توقيع التطبيق — يحتاجها الخادم لتفتح روابط الموقع داخل التطبيق مباشرة (ملف assetlinks.json).

## 5) تم التحقق منه في هذا الإصدار (1.2.0 — 14)

- `targetSdk 36`، `minSdk 24`
- كل المكتبات الأصلية 64-bit متوافقة مع صفحات الذاكرة 16 KB (شرط Google الجديد)
- الصلاحيات: الإنترنت، الكاميرا (الباركود)، الإشعارات فقط — بدون موقع، بدون صلاحيات حساسة، بدون AD_ID
- التوقيع بمفتاح الرفع يعمل (جُرّب بمفتاح تجريبي وحُذف)
- الدفع بالبطاقة مخفي في التطبيق («قريباً»)، والمساعدة «ديما» مخفية
- صفحة حذف الحساب والخصوصية تعملان على الموقع
